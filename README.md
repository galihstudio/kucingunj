# 🐱 Kucing UNJ — Perkucingan di UNJ

Portal web interaktif komunitas pencinta kucing di lingkungan **Universitas Negeri Jakarta (UNJ)**.

🔗 **Akses Website Resmi:** https://kucingunj.ai.studio

## ✨ Fitur Utama
- **MeowMaps:** Peta satelit interaktif Kampus UNJ (Kampus A: Blok M, Bundaran, Tabi, Spiral, Pustikom, serta Kampus B, D, dan E) lengkap dengan penentuan lokasi real-time dan rute jalan akurat.
- **MeowAi:** Asisten virtual interaktif bertenaga **GaninAi** yang mendukung percakapan teks, analisis gambar, dan input suara.
- **Cuaca & Kualitas Udara Kampus:** Pemantauan suhu, kondisi cuaca, IQAir, dan info gempa terkini secara real-time.
- **Komunitas Hooman, Volunteer & Donasi QRIS:** Sistem akun terenkripsi dengan peringkat *Paw* interaktif serta kanal donasi transparan untuk kesejahteraan kucing kampus UNJ.
